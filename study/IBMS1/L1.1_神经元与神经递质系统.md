# Lecture1.1 神经元与神经递质系统

## 一、神经元的形态与功能（Neuronal Morphology）

神经元是神经系统的基本功能单位，形状多样。可以把它想象成一台**信号收发器**：

- **树突 (Dendrites)**：像天线一样，负责接收来自其他神经元的信号（输入区）。
- **轴突 (Axons)**：像电缆一样，负责发送信号给其他神经元（输出区）。
- **胞体 (Soma)**：像主机，包含细胞核，负责维持细胞生命。

🧠 有些神经元没有轴突或树突，形态非常多样，功能也各不相同。

---

## 二、神经递质（Neurotransmitters）——信号的“信使”

神经元之间通过 **突触 (Synapse)** 沟通，靠的是神经递质。可以把它理解为信使，把信号从一个神经元传递给下一个。

文档中提到的几类主要神经递质：

1. **氨基酸类 (Amino acids)**
   - Glutamate（谷氨酸）：兴奋性（让下一个神经元更容易兴奋）
   - GABA（γ-氨基丁酸）：抑制性（让下一个神经元更难兴奋）
   - Glycine（甘氨酸）：也是抑制性
2. **单胺类 (Monoamines)**
   - Dopamine（多巴胺）
   - Noradrenaline（去甲肾上腺素）
   - Serotonin（5-HT，血清素）
3. **肽类 (Peptides)**
   - 如 Oxytocin（催产素）、Opioids（阿片类）
4. **其他**
   - Nitric oxide（一氧化氮）、Adenosine（腺苷）、Acetylcholine（乙酰胆碱）

---

## 三、神经递质受体（Receptors）——信号的“接收器”

神经递质必须与受体结合才能起作用。受体主要有两类：

- **离子通道型受体 (Ionotropic receptors)**：直接控制离子通道开关，反应快。
- **G蛋白偶联受体 (GPCRs)**：通过内部信号分子间接作用，反应慢，但持久。

📡 比喻：离子通道型像“手动开关灯”，GPCRs像“声控灯”——慢一点但更灵活。

---

## 四、离子的分布与膜电位（Membrane Potential）

神经元静息时，膜内外离子分布不均衡：

- Na⁺ 和 Ca²⁺ 主要在**细胞外**
- K⁺ 主要在**细胞内**
- Cl⁻ 主要在**细胞外**

这种不均衡导致膜电位约为 **-70 mV**（细胞内比细胞外负）。

⚡ 比喻：像电池的正负极，储存着“电势能”。

---

## 五、兴奋与抑制的离子基础

| 打开的离子通道 | 膜电位变化 | 效果 |
| :--- | :--- | :--- |
| Na⁺ 或 Ca²⁺ | **去极化（变正）** | 兴奋 |
| K⁺ 或 Cl⁻ | **超极化（变负）** | 抑制 |

🎯 前因后果：  
如果神经递质打开 Na⁺ 通道 → 去极化 → 更容易产生动作电位 → **兴奋**。  
如果打开 Cl⁻ 通道 → 超极化 → 更难产生动作电位 → **抑制**。

## 六、主要神经递质详解：Glutamate 与 GABA

### 🟢 Glutamate（谷氨酸）——大脑的“油门”
是中枢神经系统（CNS）最主要的**兴奋性**神经递质。

通过两类受体作用：

#### 1. AMPA 受体
- 离子通道型，打开后允许 Na⁺ 和 K⁺ 通过。
- 反转电位 (reversal potential) 接近 0 mV，因此激活后导致**去极化**。
- 是动作电位产生的主要驱动力。

#### 2. NMDA 受体
- 也允许 Na⁺、K⁺ 和 Ca²⁺ 通过。
- **特殊之处**：在静息电位时被 Mg²⁺ 堵塞。
- 只有当细胞已稍微去极化（比如通过 AMPA 受体），Mg²⁺ 才会被推开，NMDA 受体才激活。
- 这时 Ca²⁺ 进入细胞，参与学习、记忆等长期变化。

🚗 比喻：AMPA 像“轻踩油门”，NMDA 像“深踩油门并打开氮气加速”，但前提是车已经在动。

---

### 🔴 GABA（γ-氨基丁酸）——大脑的“刹车”
是 CNS 最主要的**抑制性**神经递质。

主要通过 **GABAₐ 受体**（离子通道型）起作用：
- 允许 Cl⁻ 通过
- 反转电位约 -75 mV（比静息电位更负）
- 激活后导致**超极化** → 抑制动作电位

🛑 比喻：GABA 像“踩刹车”，让神经元更难兴奋，防止大脑过度活跃。

---

## 七、总结（Summary）

| 项目 | 说明 |
| :--- | :--- |
| 神经元结构 | 树突（输入）、轴突（输出）、胞体（控制中心） |
| 主要兴奋性递质 | Glutamate（谷氨酸） |
| Glutamate 受体 | AMPA（快速去极化）、NMDA（需去极化后激活，允许 Ca²⁺ 进入） |
| 主要抑制性递质 | GABA（γ-氨基丁酸） |
| GABA 受体 | GABAₐ（Cl⁻ 通道，超极化） |
| 离子作用规律 | Na⁺/Ca²⁺ → 去极化 → 兴奋；K⁺/Cl⁻ → 超极化 → 抑制 |
